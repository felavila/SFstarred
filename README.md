# SFstarred

`SFstarred` is a Python package for working with astronomical image data.

## Installation

Create and activate a Conda environment with Python 3.12:

```bash
conda create -n sfstarred python=3.12
conda activate sfstarred
````

Go to the directory where the package is located:

```bash
cd path/to/SFstarred
```

Install the package in editable mode:

```bash
pip install -e .
```

This allows you to modify the source code and use the updated version without reinstalling the package.

To test the installation, run:

```bash
python -c "import SFstarred; print('SFstarred installed successfully')"
```
